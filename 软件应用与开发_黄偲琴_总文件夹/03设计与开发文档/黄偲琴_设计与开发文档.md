## 第一章 需求分析

邦典是藏族女性传统服饰的重要组成部分，承载着丰富的文化内涵和历史价值。随着现代化进程的加速，这一非物质文化遗产面临着传承危机。本项目旨在通过数字化手段，建立一个综合性的邦典文化传承平台。

### 1.1 开发背景
邦典作为藏族文化的重要载体，其传统织造技艺和文化内涵亟待保护和传承。通过建立数字化平台，可以：
- 系统整理和保存邦典文化资源
- 为用户提供便捷的文化学习渠道
- 促进邦典文化的传播与交流

### 1.2 功能需求
| 模块 | 功能描述 | 优先级 |
|------|---------|--------|
| 邦典浏览 | 按分类、地域浏览邦典信息 | 高 |
| 图片展示 | 大图查看、多图展示 | 高 |
| 收藏功能 | 收藏喜欢的邦典 | 中 |
| 评论互动 | 用户评论和回复 | 中 |
| 用户认证 | 注册、登录、个人中心 | 高 |
| 管理后台 | 数据统计、内容管理 | 中 |

### 1.3 面向用户
- **普通用户**：对邦典文化感兴趣的浏览者
- **文化研究者**：需要查阅邦典资料的学者
- **管理员**：平台管理者

## 第三章 详细设计

### 3.1 数据库设计

**users表**（用户表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 用户ID（主键） |
| username | VARCHAR(50) | 用户名 |
| password_hash | VARCHAR(255) | 密码哈希 |
| email | VARCHAR(100) | 邮箱 |
| role | ENUM | 角色（user/admin） |

**bondians表**（邦典表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 邦典ID（主键） |
| name | VARCHAR(100) | 名称 |
| type_id | BIGINT | 类型ID（外键） |
| region | VARCHAR(50) | 地域 |
| material | VARCHAR(50) | 材质 |
| image_url | VARCHAR(255) | 图片URL |

**comments表**（评论表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 评论ID（主键） |
| bondian_id | BIGINT | 邦典ID（外键） |
| user_id | BIGINT | 用户ID（外键） |
| content | TEXT | 评论内容 |

**favorites表**（收藏表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 收藏ID（主键） |
| user_id | BIGINT | 用户ID（外键） |
| bondian_id | BIGINT | 邦典ID（外键） |

### 3.2 API接口设计

| API路径 | HTTP方法 | 功能描述 |
|---------|---------|---------|
| /api/auth/register | POST | 用户注册 |
| /api/auth/login | POST | 用户登录 |
| /api/bondians | GET | 获取邦典列表 |
| /api/bondians/:id | GET | 获取单个邦典 |
| /api/comments | POST | 发表评论 |
| /api/favorites | POST | 添加收藏 |
| /api/favorites/:id | DELETE | 删除收藏 |
| /api/stats | GET | 获取统计数据 |

### 3.3 界面设计

**首页设计要点：**
- 顶部导航栏：logo、导航菜单、搜索框
- 轮播图：展示特色邦典
- 分类展示：按颜色分类展示
- 地域展示：西藏地图展示各地区特色
- 文化介绍：邦典文化简介

**设计风格：**
- 主色调：藏红色、金色、白色
- 字体：思源黑体

## 第五章 安装及使用

### 5.1 环境要求
- Node.js >= 18.0.0
- MySQL >= 8.0.0

### 5.2 安装步骤

```bash
# 1. 进入项目目录
cd server

# 2. 安装依赖
npm install

# 3. 配置环境变量
# 复制 .env.example 为 .env，修改数据库配置

# 4. 创建数据库
mysql -u root -p -e "CREATE DATABASE bondian_platform;"

# 5. 导入数据库结构
mysql -u root -p bondian_platform < db/schema.sql

# 6. 启动服务
npm start
```

### 5.3 配置说明

**.env文件配置：**
```env
PORT=3000
DB_HOST=127.0.0.1
DB_USER=root
DB_PASSWORD=
DB_NAME=bondian_platform
JWT_SECRET=your_secret_key
```

### 5.4 使用说明

**访问方式：**
- 前端页面：打开 `index.html`
- 后端API：http://localhost:3000

## 第六章 项目总结

### 6.1 项目成果
本项目成功实现了邦典文化传承平台，主要成果包括：
- 建立了邦典文化数据库，包含分类、地域、图片等信息
