=========================================
        设计与开发文档 - 文件说明
=========================================

一、文件夹作用
-------------
本文件夹包含项目的完整设计与开发文档，用于评委了解项目的设计思路和技术实现。

二、文件结构
-----------
├── 黄偲琴_需求分析文档.pdf     # 需求分析说明
├── 黄偲琴_系统设计文档.pdf     # 系统架构设计
├── 黄偲琴_数据库设计文档.pdf   # 数据库设计说明
├── 黄偲琴_功能模块说明.pdf     # 功能模块详细说明
└── 黄偲琴_技术文档.pdf         # 技术实现文档

三、文件说明
-----------
1. 需求分析文档：包含项目背景、用户需求、功能需求等
2. 系统设计文档：包含系统架构、模块划分、流程图等
3. 数据库设计文档：包含ER图、表结构设计等
4. 功能模块说明：详细描述各功能模块的实现
5. 技术文档：包含技术选型、关键技术实现等
