=========================================
          邦典文化传承平台 - 项目说明
=========================================

一、项目简介
----------
本项目是一个基于Web的藏族邦典文化传承平台，旨在通过数字化手段保护和传承国家级非物质文化遗产——邦典织造技艺。

二、主要功能
----------
1. 首页展示 - 邦典文化介绍
2. 文化解码 - 历史渊源、色彩密码、制作工艺、人生阶段
3. 设计工坊 - 交互式邦典设计工具
4. 邦典图鉴 - 按地区分类浏览不同风格的邦典
5. 作品广场 - 用户作品展示和互动
6. 数据洞察 - 可视化数据展示
7. 管理员后台 - 作品管理、用户管理

三、技术栈
----------
- 前端：HTML5 + CSS3 + JavaScript
- 后端：Node.js + Express
- 数据库：SQLite
- 部署平台：Railway

四、文件夹结构
--------------
├── 01 作品与答辩材料/     # 报名表、PPT、视频等
├── 02 素材与源码/         # 项目源代码
├── 03 设计与开发文档/     # 设计文档
└── 04 作品演示视频/       # 演示视频

五、在线访问地址
--------------
https://bangdian-platform-production.up.railway.app

六、本地运行方式
--------------
1. 进入 server 目录
2. 运行 npm install 安装依赖
3. 运行 npm start 启动服务
4. 访问 http://localhost:3000
