邦典文化传承平台

一、文件夹说明：
01作品与答辩材料/ - 存放报名表、概要表、原创性声明、学生证、答辩PPT及视频
02素材与源码/ - 存放项目源代码和代表性素材
03设计与开发文档/ - 存放设计与开发文档
04作品演示视频/ - 存放作品演示视频

二、文件描述：
- 作品名称：邦典文化传承平台
- 类别：软件应用与开发 -> Web应用与开发
- 作者：黄偲琴

三、运行方式：
1. 进入 server 目录
2. 执行 npm install 安装依赖
3. 配置 .env 文件（数据库连接信息）
4. 执行 npm start 启动服务
5. 打开 index.html 访问前端页面

- 数据库：MySQL 8.0+
- 认证：JWT + bcryptjs
