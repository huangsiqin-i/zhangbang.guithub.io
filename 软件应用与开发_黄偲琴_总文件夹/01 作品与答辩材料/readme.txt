一、文件夹作用
-------------
本文件夹包含参赛所需的个人材料和答辩相关文档，用于评委审核和答辩环节使用。

二、文件结构
-----------
├── 黄偲琴_报名表.pdf           # 参赛报名表（签字盖章扫描件）
├── 黄偲琴_作品信息概要表.pdf    # 作品信息概要表
├── 黄偲琴_原创性声明.pdf        # 原创性声明（签字扫描件）
├── 黄偲琴_学生证.pdf           # 学生证扫描件

三、文件说明
-----------
1. 报名表：需签字并加盖学校公章后扫描
2. 作品信息概要表：包含作品简介、创新点、技术亮点等
3. 原创性声明：需本人签字确认
4. 答辩PPT：建议10-15页，包含项目介绍、技术架构、功能演示等
5. 答辩视频：需展示PPT内容和网站实际演示
