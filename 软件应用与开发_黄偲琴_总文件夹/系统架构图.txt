===========================================================
                    拼图小游戏功能介绍
===========================================================

【功能概述】
邦典拼图游戏是设计工坊模块中的一个互动小游戏，旨在通过游戏化方式增强用户对邦典文化的认知和兴趣。

【游戏特性】
┌───────────────────────────────────────────────────────┐
│ 功能特性           │ 说明                             │
├─────────────────────┼─────────────────────────────────┤
│ 游戏模式           │ 4×4数字拼图，共16个拼图块        │
│ 图片来源           │ 使用用户当前编辑的邦典图案        │
│ 计时系统           │ 实时显示游戏用时                  │
│ 计数统计           │ 记录玩家移动拼图块的次数          │
│ 提示功能           │ 显示正确拼图位置参考              │
│ 自动完成           │ 一键还原拼图解决方案              │
│ 胜利判定           │ 自动检测拼图完成状态              │
│ 成绩展示           │ 显示最终用时和移动次数            │
└─────────────────────┴─────────────────────────────────┘

【游戏玩法】
1. 用户在设计工坊完成邦典图案设计后，点击"玩拼图游戏"按钮
2. 系统将当前图案切割成16个拼图块并打乱顺序
3. 用户点击或拖拽拼图块进行移动（只能移动空格相邻的块）
4. 将所有拼图块还原到正确位置即获胜
5. 游戏记录用时和移动次数，完成后展示成绩

【技术实现】
• 前端技术：HTML5 Canvas + JavaScript
• 游戏算法：经典15拼图问题，支持可解性检测
• 交互方式：点击移动 + 拖拽移动
• 数据存储：本地状态管理，无需后端交互

【文化意义】
通过拼图游戏的形式，让用户在娱乐中加深对邦典图案的印象，
感受邦典纹样的精美细节，促进非遗文化的传播与传承。
