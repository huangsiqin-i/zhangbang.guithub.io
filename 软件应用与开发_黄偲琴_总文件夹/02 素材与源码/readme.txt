            素材与源码 - 文件说明

一、文件夹作用
-------------
本文件夹存放作品源码与素材，包含网站前端代码、后端代码、图片资源及数据库文件。

项目为Web应用，已部署上线，可直接访问：
https://bangdian-platform-production.up.railway.app

三、文件说明
-----------
1. 黄偲琴_项目源码.zip
   - 包含完整的前端页面和后端服务代码
   - 数据库已预填充邦典图案、传承人等示例数据
   - 无需额外配置，解压后可直接部署运行

2. 黄偲琴_素材/
   - 包含项目所有原始图片素材
   - 涵盖邦典图案、传承人照片、制作工艺、人生阶段等主题
   - 可用于网站开发和宣传材料制作

3. images/
   - 网站所需的所有图片资源
   - 包含邦典图案、传承人照片、人生阶段图片、装饰图片等

4. server/
   - Node.js + Express 后端服务框架
   - SQLite 嵌入式数据库，开箱即用
   - 包含控制器、路由、中间件等完整架构

四、本地运行方式
---------------
1. 解压 黄偲琴_项目源码.zip
2. 进入解压后的目录
3. 进入 server 子目录
4. 运行 npm install 安装依赖
5. 运行 npm start 启动服务
6. 访问 http://localhost:3000
