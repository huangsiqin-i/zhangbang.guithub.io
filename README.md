# 编织人生 - 藏族邦典文化数字体验平台

## 项目简介

"编织人生"是一个致力于传承和传播藏族邦典文化的数字体验平台。通过现代化的Web技术，将藏族传统邦典文化以全新的方式呈现给大众，让古老的文化在数字时代焕发新生。

### 项目背景

邦典是藏族妇女围在腰上的传统服饰，不仅是藏族服饰文化的重要组成部分，更是藏族女性生命历程的象征。本项目旨在通过数字化手段，保护和传承这一珍贵的非物质文化遗产。

### 技术亮点

- **响应式设计**：完美适配桌面端和移动端
- **AI图像生成**：基于邦典色系的AI艺术创作
- **虚拟试穿**：沉浸式邦典试穿体验
- **文化解码**：深入解读邦典的色彩、纹样和工艺
- **多语言支持**：支持中文、英文、藏语三种语言

## 功能模块

### 1. 文化解码
- 雪域六色密码：解读邦典六大经典色系的文化内涵
- 邦典工艺全解：展示从选材到成品的完整制作流程
- 生命叙事：呈现藏族女性与邦典相伴的生命历程
- 图案哲学：解析邦典纹样的象征意义

### 2. 设计工坊
- 颜色搭配器：自由组合邦典色彩
- 纹样选择：丰富的传统纹样库
- 实时预览：即时查看设计效果
- 作品保存：保存和分享设计作品

### 3. 虚拟试穿
- 3D虚拟模特试穿
- 多种款式选择
- 场景切换：不同场景试穿效果
- 社交分享：分享试穿照片

### 4. 学习路径
- 课程体系：系统化的邦典文化学习
- 成就徽章：激励学习进度
- 进度追踪：记录学习历程
- 互动问答：巩固知识掌握

### 5. 非遗传承
- 传承人介绍：展示国家级非遗传承人的故事
- 技艺展示：视频演示传统工艺
- 文化社区：用户交流分享平台

### 6. AI创作
- 色系生成：基于不同色系生成艺术作品
- 风格转换：多种艺术风格可选
- 创意灵感：激发设计灵感

## 快速开始

### 环境要求

- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 无需后端服务器，纯前端运行

### 运行方式

1. **本地运行**：
   ```bash
   # 直接用浏览器打开 index.html
   open index.html
   ```

2. **开发服务器**：
   ```bash
   # 使用Python启动简易服务器
   python -m http.server 8000
   # 访问 http://localhost:8000
   ```
